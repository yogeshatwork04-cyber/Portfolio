# Yogesh — Developer Portfolio

Personal developer portfolio showcasing high-performance real-time systems, event-driven backends, and AI diagnostic platforms.

## 🚀 Overview

- **Architecture:** Minimalist modern tech design built with Vanilla HTML5, CSS3, and JavaScript (ES6+).
- **Typography & Theme:** Google Fonts `Inter` + `JetBrains Mono` with dark monochromatic styling and subtle luminous accents.
- **Form Integration:** Asynchronous FormSubmit AJAX pipeline for direct inbox delivery with zero page reload.

## 🌟 Featured Projects

1. **SyncDraw — Real-Time Collaborative Whiteboard**
   - Event-driven collaborative canvas supporting 10+ concurrent users per room with bidirectional stroke streaming.
   - Built with React, Node.js, Socket.io, Google OAuth 2.0, JWT, and Docker Compose.
   - [Live Demo](https://sync-draw-eight.vercel.app/)

2. **CodeLens AI — Automated Code Review Agent**
   - AI developer tool auditing code snippets for Big-O time and space complexity bottlenecks and security flaws.
   - Powered by Google Gemini 3.5 Flash, FastAPI, Docker, and Render.
   - [Live Demo](https://codelens-ai-ixqc.onrender.com/) • [Source Code](https://github.com/anshullakra007/codelens-ai)

3. **Daddy’s Garage — AI Garage Management Platform**
   - Full-stack platform featuring RBAC and an integrated RAG diagnostic assistant using FAISS vector indexing and Gemini API.
   - Built with FastAPI, Python, SQLAlchemy, LangChain, and React.
